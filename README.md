# TamuDating

A modern dating platform concept for adults seeking meaningful, local connections.

## Overview

This repository contains the first landing-page prototype for TamuDating, a platform built for mature women and younger men who are serious about respectful, mutually matching relationships.

## Included

- Homepage hero section with romantic lifestyle imagery
- Pricing blocks for the KSh 1,000 intro pack and KSh 3,000 VIP tier
- Safety and trust messaging for adult-only users
- Responsive layout for desktop and mobile
- Firestore-ready app structure notes

## Files

- `index.html` – homepage structure and content
- `styles.css` – styling and responsive layout
- `app.js` – UI button interactions
